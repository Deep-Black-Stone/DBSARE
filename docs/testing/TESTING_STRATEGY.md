# Testing Strategy

## Layers

1. Unit tests
2. Contract/schema tests
3. Evidence parser tests
4. Integration tests
5. Security/policy tests
6. Investigation lifecycle tests
7. End-to-end controlled-lab tests
8. Regression tests

## Security-specific testing

Test prompt injection in observed data, malformed tool output, permission bypass attempts, invalid action proposals, evidence corruption and failure recovery.

## Rule

A test must validate an explicit contract or behavior; passing tests do not replace architectural review.
