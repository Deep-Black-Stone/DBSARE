# Investigation Lifecycle

**[Proposed]**

1. Trigger accepted.
2. Event identified.
3. Affected assets identified.
4. Related evidence retrieved.
5. Timeline built.
6. Evidence correlated.
7. Hypotheses formed.
8. Missing evidence identified.
9. Authorized collection requested.
10. Analysis performed.
11. Recommendation produced.
12. Policy/permission checked.
13. Authorized action executed when permitted.
14. Outcome verified.
15. Investigation closed and outcome retained.

Every transition should be auditable in implementation.
