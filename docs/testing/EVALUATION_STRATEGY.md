# Evaluation Strategy

DBSARE evaluation should measure system behavior rather than model fluency alone.

## Candidate dimensions

- Evidence extraction accuracy
- Entity/relationship correctness
- Correlation quality
- Hypothesis quality
- Investigation completeness
- False-positive / false-negative behavior
- Provenance completeness
- Action-policy compliance
- Verification success
- Recovery from malformed/untrusted input
- Auditability
- Resource usage

Evaluation should use reproducible controlled scenarios.
