# Memory Architecture

## Memory definition

Memory is what DBSARE deliberately retains from interaction and experience.

## Required conceptual categories

1. Short-Term Context
2. Long-Term Memory
3. Cybersecurity Knowledge
4. Environment State
5. Investigation History

## Lifecycle

```
Observation / Interaction
 → Candidate Memory
 → Validation
 → Classification
 → Retention Policy
 → Storage
 → Retrieval
 → Use
 → Update / Expire
```

Memory must not silently convert uncertain observations into permanent facts.

## Learning boundary

Learning in the initial system means validated knowledge or memory updates. Automatic model-weight modification is outside the initial scope.
