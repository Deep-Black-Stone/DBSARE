# PFE Demonstration Scenario

1. Establish a known lab baseline.
2. Generate an authorized security event.
3. Collect network, host, and log evidence.
4. Normalize and correlate evidence.
5. Build the affected environment view.
6. Create and test investigation hypotheses.
7. Request missing authorized evidence when needed.
8. Produce an auditable explanation and recommendation.
9. If an action is enabled, apply policy and approval controls.
10. Verify the result and retain the outcome.

The demonstration should expose source evidence, relationships, timeline, confidence, investigation state, policy decisions, and report output.
