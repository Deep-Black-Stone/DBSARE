# Data Contracts

DBSARE uses explicit contracts between collectors, evidence processing, Brain, Memory, reasoning, investigation, policy, and reporting.

## Contract categories
Evidence, Host, Service, Port, Network Connection, DNS Event, Vulnerability, Alert, Incident, Investigation, Hypothesis, Observation, Action, Permission, Audit Event, Memory Entry, Knowledge Item, Relationship.

## Common metadata
Where applicable: stable identifier, schema version, timestamp, source, provenance, confidence, sensitivity, and related entity identifiers.

## Semantic distinctions
Observed Fact; Derived Fact; Hypothesis; Inference; Recommendation; Verified Outcome.

Contracts are conceptual in Phase 0 and must be versioned before implementation.
