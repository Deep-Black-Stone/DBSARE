# Reasoning Architecture

## Reasoning loop

```
Evidence A + B + C
 → Correlation
 → Hypothesis
 → Investigation
 → Confidence / Uncertainty
 → Conclusion
 → Recommended Next Step
```

## Traceability

DBSARE should expose an auditable decision summary containing:

- relevant evidence
- observed facts
- derived relationships
- hypotheses considered
- confidence/uncertainty
- recommendation
- action taken
- verification result

This is an audit-oriented reasoning trace, not disclosure of private model chain-of-thought.
